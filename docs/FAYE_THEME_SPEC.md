# Faye Codex 主题视觉规范

## 设计方向

主题名为 **Bebop After Midnight**。主视觉使用 Faye 左侧半身构图；右侧保留大面积
近黑区域，让对话、代码与审批内容持续可读。界面不复刻动画截图，而是从图中提取五个
可复用线索：飞船冷黑、酒红皮革、绿眼与烟雾、烟头余烬、旧金发带。

主题只改变视觉属性，不替换或隐藏 Codex 内容，不改变字体、字号、布局、交互和业务
文案。玛奇玛仍是 CLI 默认主题，两套主题使用不同 CSS、样式节点、运行状态和 Chromium
profile。

## 可修改令牌

所有主题私有令牌位于 `themes/faye.css` 顶部：

| 分组 | 令牌 | 用途 |
| --- | --- | --- |
| 底色 | `--fy-void-*`, `--fy-ink-900`, `--fy-oxide-*` | 应用背景、面板、悬浮层 |
| 主色 | `--fy-blood-*` | 酒红外套、选中态、主按钮、用户消息 |
| 活动色 | `--fy-iris-*` | 绿眼/烟雾色，链接、边界、Thinking 与工具调用 |
| 瞬时提示 | `--fy-ember-400` | 输入光标、推理入口和活动高光 |
| 稀有强调 | `--fy-gold-400` | 发带色，只用于推理强度等小面积信息 |
| 文本 | `--fy-ivory-*` | 正文、次级文字、弱提示 |
| 语义色 | `--fy-green-400`, `--fy-red-400` | 成功、失败、Diff 增删，不能被酒红主色替代 |
| 玻璃 | `--fy-glass-*`, `--fy-edge-*` | 侧栏、消息、代码、描边与聚焦 |

## 组件覆盖

- 背景与侧栏：人物位于左侧，侧栏保持轻度透明；主内容右侧逐步压暗。
- 标签与导航：石墨黑表面，当前项以酒红底和烟雾青边界区分。
- 首页建议卡：冷黑玻璃，悬停时增加酒红反光，不使用高亮白底。
- Composer：冷黑控制玻璃；聚焦使用烟雾青边界，光标和推理入口使用烟头橙。
- 用户消息：酒红半透明气泡；助手正文：中性石墨阅读层，避免双方都染成红色。
- Thinking / 工具调用：`[data-local-conversation-item-target-ids]` 使用烟雾青左缘和
  余烬角光；`.loading-shimmer-pure-text` 使用青—橙—青的活动色谱。
- 计划与状态：`[data-nested-in-plan]` 使用冷黑面板；完成、进行中、失败分别保留
  绿、烟雾青和红色语义。
- Markdown / 代码：正文保持冷灰白；行内代码用烟雾青；代码块使用近黑表面。
- 终端：保持完整 ANSI 色区分；背景只加入极弱酒红反光。
- Diff / Review：新增为绿色，删除为红色，主题色只用于框架和标题。
- 审批、对话框、菜单、浮层：统一深色飞船玻璃与青色细边。
- 选区、焦点、滚动条：选择使用酒红；键盘焦点使用烟雾青；滚动条保持低对比。

## 无障碍与安全边界

- `forced-colors` 模式移除插画和装饰阴影。
- `prefers-reduced-motion` 模式关闭颜色过渡。
- 不声明字体族、字号、行高、字距、尺寸、间距、定位或业务 DOM 可见性。
- 不覆盖指针事件；唯一例外是侧栏纯装饰伪元素的 `pointer-events: none`。
- 每个主题使用独立样式 ID、页面标记、守护状态和 profile，停止 Faye 不会停止玛奇玛。
