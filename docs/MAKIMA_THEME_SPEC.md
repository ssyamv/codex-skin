# 玛奇玛静态主题视觉规范

## 设计意图

主题方向是“鼠尾草契约档案室”：整窗像一张浅亚麻纸上的玛奇玛档案插画，以鼠尾草、
旧铜圆环和低饱和酒红建立识别。角色位于左侧主区，脸部避开侧边栏边缘；背景连续穿过
侧栏与对话区，中央至右侧用低细节留白和半透明阅读层保证可读性。

原有信息架构、控件尺寸和字体全部保留。视觉变化集中于颜色、既有边框颜色、阴影、
背景层次、玻璃材质和不接收事件的装饰层。

| 炭墨 | `--cs-makima-ink-900` | `#30342f` | 主文字与代码正文 |

| 契约酒红 | `--cs-makima-blood-500` | `#924554` | 主操作与选中态 |
| 旧铜 | `--cs-makima-iris-400` | `#876b3e` | 焦点、边界与圆环纹样 |

## 主视觉与降级

- 母版为 1672×941 横版插画，玛奇玛位于画面左侧约三分之一。
- 左侧约 18% 允许身体轮廓延伸到半透明侧栏下方，但完整脸部位于侧栏之外。
- 中央至右侧约 55% 为低细节负空间；浅亚麻纸纹、植物线稿与旧铜同心圆都烘焙进图片，
  不创建额外覆盖 DOM。
- 运行素材是 1672×941 静态 WebP；不编译、不加载 animated WebP。
- `prefers-reduced-motion: reduce` 关闭界面颜色过渡；`forced-colors` 完全移除插画。
- 不使用 CSS keyframes、视频标签、滚动视差或输入监听；ResizeObserver 只同步右侧面板
  边界，使固定标题栏遮罩不会压暗标签文字，不写入尺寸或改变布局。

## 区域设计

### 标题栏与侧栏

标题栏使用由浅亚麻向鼠尾草透明层自然衰减的纵向渐变，不再使用底部发丝线或在右侧
面板边界硬切色。侧栏不使用模糊或独立装饰纹理，让整窗背景连续穿过；只叠加
38%–52% 的亚麻与鼠尾草阅读层。唯一 `::before` 层负责柔化上下边缘，并固定为
`pointer-events: none`。

活动任务采用浅酒红纸面、左侧定位线和独立的右侧工作状态环；悬停使用鼠尾草纸面，
不移动、不缩放，也不修改任务行尺寸。

### 主工作区与对话

主区只叠加 8%–38% 的浅亚麻渐变；人物和植物线稿能连续穿过对话区，右侧正文仍有
稳定留白。Assistant 最终回复使用 56% 亚麻阅读层和柔和阴影，不增加 padding，
不改变正文折行；用户消息使用浅酒红纸面。审批卡用酒红定位线突出权限语义。

### 首页建议卡与浮层

建议卡、菜单、环境信息和 Dialog 使用浅亚麻纸面、旧铜内描边和低扩散暖灰阴影。
菜单与浮层保持 98%–99% 不透明，避免背景细节干扰选项；不覆盖 Radix 的定位、层级
或命中区域。

### Composer

Composer 保持原尺寸和内部结构。默认边界为 26% 旧铜；聚焦时提高酒红边界并使用
低扩散暖棕阴影。输入节点、快捷键、附件、权限、模型按钮和发送按钮仍由原生 DOM
处理，主题不注册任何事件。

### 代码、终端与 Diff

代码块和终端使用 98% 暖米灰表面；只读代码预览的 Shadow DOM 同步注入暖米灰底、深暖棕
正文与红、金、青语法色；Diff 使用完全不透明的暖米灰表面及浅绿、浅红行底，避免
半透明增删色与组件内部表面合成出脏色块。新增、删除、警告、错误、Git
decoration 和 ANSI 色各自保留语义；主题只补足背景、边界、选区和缺失的颜色 token，
不设置任何字体属性，也不改变行号、折叠、滚动或选择行为。

### Thinking、工具与计划

Thinking 运行文字使用高对比深旧铜，不覆盖整行背景；工具读取、搜索、命令执行按
活动组显示为半透明鼠尾草面，展开详情保持浅亚麻。文件活动链接使用低透明旧铜表面。
计划步骤使用古铜金定位线，完成、运行和失败继续分别使用绿、金、红语义。
活动标题单独保留 10 px 左侧呼吸空间；命令详情本身不增加内边距，避免改变折行。
所有规则只命中 Codex 自带的稳定活动标记，不根据文案判断类型，也不改变展开按钮、
停止操作、计划状态或命令输出结构。

## 字体与排版

主题明确不设置 `font`、字体族、字号、行高和字距，也不写入 Codex/VS Code 字体
变量。正文、代码、按钮、终端和 Composer 全部继承当前 Codex 配置。运行态探针会
比较启用前后的 computed style，而不是只检查 CSS 源码。

## 安全与可访问性

- 安全验证器拒绝尺寸、间距、overflow、position、flex/grid、transform、border
  宽度、内容隐藏、布局变量和持续 CSS animation。
- 唯一可定位的装饰层具有精确选择器和值白名单。
- 焦点环不被移除；成功、错误、Diff 和终端语义色保持可区分。
- 主视觉始终静止，强制颜色模式移除图片与非必要阴影。
- 背景不使用 `background-attachment: fixed`；模糊只用于稳定的小面积表面，最大 8 px。

## 运行时约束

每个 Codex 页面最多存在一个 `#codex-skin-makima`。页面重载时通过
`Page.addScriptToEvaluateOnNewDocument` 自动恢复；守护进程还会轮询新页面和样式
健康状态。停止命令会撤销新文档脚本、删除样式节点和根主题标记，然后关闭专用
profile 的 Codex 与本机调试端口。

运行时只连接 `127.0.0.1` 上端口完全匹配的 `app://-/index.html` 页面。启动器会先
拒绝仍与普通 Codex 共享同一 `CODEX_HOME` 的并发启动；它不复用默认 Chromium
profile，也不修改官方应用包、`app.asar` 或代码签名。
